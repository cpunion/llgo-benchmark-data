# LLGo benchmark data

This repository stores continuous benchmark history generated by
`github-action-benchmark`. Source files live on `main`; generated history and
series data live on `pages`. The Pages workflow combines the generated history
with the presentation in `site/`; benchmark producers do not own site HTML.
The dashboard groups related measurements and renders comparable metrics as
multiple time-series curves. Unknown future core benchmarks remain visible in
an `Other` group.

Only the matching `<owner>/llgo` repository may request a Pages deployment.
Pull-request code never receives the token that writes benchmark history.
