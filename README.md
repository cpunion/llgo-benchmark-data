# LLGo benchmark data

This repository stores continuous benchmark history generated by
`setup-benchmark-go-action`. Workflow sources live on `main`; generated
history, series data, and the matching site presentation live on `pages`.
The Pages workflow deploys that generated site without replacing any of its
files, keeping the data schema and presentation in sync.

Only the matching `<owner>/llgo` repository may request a Pages deployment.
Pull-request code never receives the token that writes benchmark history.
