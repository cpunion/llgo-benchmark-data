# LLGo benchmark data

This repository stores continuous benchmark history generated by
[`setup-benchmark-go-action`](https://github.com/cpunion/setup-benchmark-go-action).
Generated history and the complete static site live on `pages`.

GitHub Pages publishes the `pages` branch from `/ (root)`. The trusted publisher
in `cpunion/llgo` is the only writer; pull-request code only uploads validated
benchmark artifacts and never receives the data-repository token.
